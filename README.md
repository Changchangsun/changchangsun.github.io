# Changchang Sun

Academic homepage: https://changchangsun.github.io/

This repository publishes the static website from the root of the `main` branch through GitHub Pages. The `.nojekyll` file keeps the HTML and assets unchanged during deployment.

The previous homepage address, https://changchangsun.github.io/Changchangsun/, redirects to the root homepage through `Changchangsun/index.html`.

Update `index.html`, `bibs/`, or `files/`, then commit and push to `origin/main` to publish changes to the main homepage.
